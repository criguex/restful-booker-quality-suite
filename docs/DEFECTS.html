Restful Booker Defect Report

Eight reproducible API defects confirmed through exploratory testing and automated as controlled expected failures.

Prepared by Cristian Guerra · Verified 16 October 2026 · Target 127.0.0.1:3001

Release position: no-go for a production contract supporting XML, decimal prices or untrusted dates. RB-002, RB-003 and RB-004 can silently corrupt business data.
ID Severity Endpoint Observed behavior Impact
RB-001 Medium GET /booking/:id XML body declares text/html. Strict clients and schema middleware may reject the response.
RB-002 High POST /booking XML false is stored as true. Financial state is silently inverted.
RB-003 High POST /booking 10.99 is returned and stored as 10. Monetary precision is lost.
RB-004 High POST /booking Invalid dates are accepted and can become 0NaN-aN-aN. Corrupt dates enter persistence and downstream workflows.
RB-005 Medium PUT/PATCH /booking/:id An absent target returns 405 instead of 404. Clients receive a misleading method error.
RB-006 Medium DELETE /booking/:id An absent target returns 405 instead of 404. Clients cannot distinguish absence from unsupported operations.
RB-007 Medium POST /booking A missing-field payload returns HTTP 500. Client errors pollute service reliability metrics and may trigger retries.
RB-008 Medium POST /auth Invalid credentials return HTTP 200. Clients, proxies and monitoring classify failed authentication as success.

Automation treatment

Nine automated checks reproduce these eight defects because RB-005 validates PUT and PATCH independently. Playwright marks them as expected failures: the pipeline remains useful while the defects are open, and a product fix produces an unexpected pass that requires the expectation to be removed.

Remaining contract clarifications

/ping returning HTTP 201 and unsupported Accept values returning HTTP 418 remain clarification points rather than confirmed blockers.
